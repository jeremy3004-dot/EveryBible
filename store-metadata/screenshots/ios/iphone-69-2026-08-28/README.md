# Every Bible 6.9-inch Editorial Screenshot Pack

This is the candidate App Store screenshot refresh produced on 2026-08-28. It replaces the previous red visual direction with warm editorial paper, Every Bible blue accents, and one navy contrast slide.

## Store Format

- Canvas: 1320 × 2868 pixels
- Display class: iPhone 6.9-inch
- Format: flattened RGB PNG without transparency

## Production Notes

- The four background artworks were generated with the built-in Image 2.0 workflow.
- The supplied app screenshots were copied byte-for-byte into `source/screens/` and composited deterministically. Image generation was not used to redraw or rewrite the app UI.
- `scripts/build_app_store_editorial_pack.sh` reproduces the final compositions from the stored sources.
- This folder is a candidate pack for review. The existing authoritative upload folders remain unchanged until this set is approved for submission.
