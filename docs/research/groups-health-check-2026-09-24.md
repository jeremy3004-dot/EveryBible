# Four Fields groups: health check (2026-09-24)

Scope: `src/screens/learn/Group{List,Detail,Session}Screen.tsx`, `src/stores/fourFieldsStore.ts`,
`src/services/groups/*`, the `send-group-notification` edge function, and the live
`groups` / `group_members` / `group_sessions` / `prayer_*` tables, policies, helpers and RPCs
(project `ganmududzdzpruvdulkg`, read-only SQL on 2026-09-24).

## State of the feature

- **The screens can't be reached.** Nothing navigates to `GroupList`. The Gather card that
  opened it was removed in 205e20eb / 767a4ced, and `linkingConfig` has no route to it. There
  is no UI for creating or joining a group, local or synced. `fourFieldsStore.createGroup` /
  `joinGroup` and `groupService.createSyncedGroup` / `joinSyncedGroup` / `leaveSyncedGroup`
  have no callers. `config.features.studyGroupsSync` is `false`.
- **Live data:** 0 rows in `groups`, `group_members`, `group_sessions` and `prayer_requests`.
- **Migrations:** every group migration in the repo has been applied live, including the
  July helper migrations that memory listed as unapplied (20260704120000, 20260711100100),
  20260910093000 and 20260923233220. `list_migrations` matches the repo for all of them. The
  only group migration not applied is the new one from this check (below).
- **Live `pg_policies`** match 20260923233220: the helpers take one argument and check only
  the caller, the scope columns are fixed by triggers, and the join code allows 10 misses per
  user per hour.

Most client findings below are therefore **latent**. They will matter when the feature is
turned on. The RLS findings apply today to anyone who calls PostgREST directly.

## What I checked and found no problem

- **Sign-out and account switching:** local groups sit in per-account buckets
  (`four-fields-storage:user:<uid>`), and the guest bucket is merged in on first sign-in.
  `GroupList` and `GroupDetail` tie remote state to the signed-in uid, so a switch refetches
  and never shows another account's synced groups.
- **RLS reads:** non-members see no groups, memberships, sessions or prayers. The helpers
  answer only for the caller. Rows can't be moved to another group or owner, and leadership
  can only pass to an existing member (checked live, and covered by the verifier).
- **Accessibility:** the icon-only back and share buttons, phase tabs and leave button all
  have roles and labels. Rows and cards take their labels from their visible text.
