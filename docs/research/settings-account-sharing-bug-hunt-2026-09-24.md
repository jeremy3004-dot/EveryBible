# Settings, account and sharing bug hunt (2026-09-24)

Scope: the More tab, every Settings row (theme, font size, language, reminders, discreet
mode, translator/council passcode entry, Clear cache, Delete account, About, Diagnostics),
Profile, and every share path (reader verse text, verse image, chapter link, chapter audio
and audio clip, Home verse-of-the-day image, lesson text/link/audio, share app, group
invitation, diagnostics export). Deep-link formats were checked against
`src/navigation/linkingConfig.ts` and `src/services/bible/deepLinkParser.ts`.

Method: code reading plus the unit and render tests below. One read-only query was run
against the live `translation_catalog` (licence counts). Nothing was tested on a device.
Areas already covered today were not repeated: reminders (plans-reminders bug hunt),
onboarding re-run after sign-out (onboarding-language bug hunt), account deletion data
(account-deletion data map), passcode lockout (translator-access options), private data
on account switch (sync/offline review).

## Verified as working

- Theme, font size, language, reminders and feedback identity each call `syncPreferences()` after `setPreferences`, which stamps each changed field. The reader's theme sheet does too.
- Sign-out and account switch reset per-user stores and preferences. The daily reminder is reconciled from preferences, so it is cancelled after a reset.
- Clear cache asks for confirmation and removes only an allowlist of re-downloadable keys. Delete account shows a warning modal that cannot be dismissed while deletion runs.
- Cancelling a share is not treated as an error: RN `Share.share` and `expo-sharing` resolve on dismiss, and every image share falls back to text share only on a real failure.
- On Android, link shares put the URL inside the message (reader chapter share, lesson `toSharePayload`).
