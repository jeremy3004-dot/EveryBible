# Phone test checklist for the next release

Written 2026-09-24. About 60 changes landed today. They passed the automatic tests, but
nobody has tried them on a real phone yet. This list is everything that still needs a
real phone. Duplicates from the separate reports have been merged.

## Before you start

- Use a proper test build (a "preview" or "production" build), not Expo Go and not the
  development app. Some items need a special development build; those are marked.
- Phones:
  - One iPhone on the current iOS.
  - One budget Android phone. The TECNO KL4 is the best one, because it is the most
    aggressive about stopping apps in the background.
  - One Pixel or Samsung phone.
  - For the "two phones" section, two phones signed in to the same test account.
  - If you can, one older Android phone (Android 11 or 12), and test with both the
    three-button bar and gesture navigation.
- Make a test account you don't mind deleting.
- "Both" means test on iPhone and on Android.
